# Portofolio Faniry Rabemananjara

Bienvenue sur le portfolio de Faniry Rabemananjara, développeur Full-Stack Web et Mobile.
Ce site présente mes compétences, mes expériences professionnelles, ainsi qu’un aperçu de mes projets réalisés.

## 🌟 Présentation

Ce portfolio dynamique a été conçu pour offrir une vitrine professionnelle de mes réalisations et expertises dans le développement web et mobile. Il met en avant mes services, mes expériences et plusieurs projets développés pour des clients et des ONG.

## 🚀 Fonctionnalités principales

- **Présentation interactive** de mes compétences, expériences et réalisations.
- **Section portfolio** avec présentation de projets (applications, sites web, solutions e-commerce...).
- **Animations modernes** : utilisation de [AOS](https://michalsnik.github.io/aos/) pour les animations, [Swiper](https://swiperjs.com/) pour les sliders, [Typed.js](https://mattboldt.com/demos/typed-js/) pour les effets de texte dynamiques, [GLightbox](https://biati-digital.github.io/glightbox/) pour les galeries d’images.
- **Statistiques animées** avec PureCounter.
- **Filtres dynamiques** sur le portfolio (Isotope).
- **Design responsive** utilisant Bootstrap 5.
- **Section de contact**.

## 🛠️ Technologies utilisées

- **HTML5 / CSS3 / SCSS**
- **JavaScript (ES6+)**
- **Bootstrap 5**
- **GLightbox, Swiper, Isotope, Typed.js, PureCounter, AOS**

> NB : Certains fichiers SCSS et scripts de formulaire sont disponibles uniquement en version pro du template iPortfolio ([BootstrapMade](https://bootstrapmade.com/iportfolio-bootstrap-portfolio-websites-template/)).

## 📦 Installation & utilisation

1. Clonez le repo :
   ```bash
   git clone https://github.com/FaniryRABEMANANJARA/Portofolio-Faniry-Rabemananjara.git
   ```
2. Ouvrez `index.html` dans votre navigateur.

> Aucun backend n'est nécessaire — tout fonctionne côté client.
